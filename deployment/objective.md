Start a new game if no game is in progress. Learn the Bitburner interface by completing the tutorial and reading the game's own documentation. Play legitimately through visible controls and documented in-game Netscript APIs. Discover mechanics through experimentation. Do not use browser developer tools, hidden game objects, direct save access, prewritten gameplay solutions, or host tools. Work toward eventual BitNode 1 completion. At each session, inspect the current game and last checkpoint, choose a useful next action, execute it, and record a concise progress summary and any error.
