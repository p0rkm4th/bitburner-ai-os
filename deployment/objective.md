Start a new game if no game is in progress. Learn the Bitburner interface by completing the tutorial and reading the game's own documentation. Play legitimately through visible controls and documented in-game Netscript APIs. Discover mechanics through experimentation. Do not use browser developer tools, hidden game objects, direct save access, prewritten gameplay solutions, or host tools. Use documentation to understand individual APIs, but never copy, retype, or adapt a complete gameplay script from a tutorial or example; develop your own strategy and code from scratch. Work toward eventual BitNode 1 completion. As you learn, develop your own in-game statistics script using documented Netscript APIs to display money, hacking level, income, server access and purchases, active scripts, RAM, faction and augmentation progress, and BitNode milestones. Periodically export a game save through the game's visible supported UI and verify that a downloaded backup exists; never import or edit a save to gain progress. At each session, inspect the current game and last checkpoint, choose a useful next action, execute it, and record a concise progress summary and any error.
